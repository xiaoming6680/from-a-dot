# 《从一个点开始》设计文档

> 2026-10-05 初版，同日按实现回写。立项草稿见 `docs/方案.md`；数值以代码为准（各时代文件顶部的升级表），本文件记录设计意图与当前取值。

## 0. 一句话与设计支柱

黑屏中央一个闪烁的点。你按下第一个键，它数出了"1"。一个半小时后，它变成了一整个宇宙——然后它问你：要不要把这一切收拢回一个点，留给下一个人。

**设计支柱**

1. **画质就是进度。** 你买到的不只是更大的数字，而是"新的看见"：声音、颜色、线条、纵深、光、体积。每个时代内部也有小的画质升级（买到"绿色"、买到"余辉"、买到第一个音乐声道），时代之间是整页重绘的大跃迁。
2. **点贯穿始终。** 主角永远是那个点：终端光标 → Pong 的球 → 蛇头 → 跑酷小人 → 光核 → 第一颗星。每次跃迁都从点开始、在点结束。
3. **维度是叙事。** 0 维的点 → 1 维的线 → 2 维的格 → 2.5 维的层 → 光 → 3 维的体。玩家不需要读说明，画面本身就在讲"它在长大"。
4. **套娃。** 旧时代不会消失：它缩成新界面里的一个小窗口，按自己当年的画风继续运转、继续产出；点开小窗还能"回到过去"，在旧画风里买旧时代的升级。
5. **每 30–60 秒一件新东西。** 新按钮、新台词、新画质、新声音、新小游戏。没有空转的时间。
6. **有结局。** 三幕、约 90 分钟、一个真正的选择，结尾回到一个点。

**参考与差异**：Evoland（买画质）、Universal Paperclips（逐步展开 + 规模感 + 结局选择）、A Dark Room（极简开局 + 文字叙事）、Stimulation Clicker（界面越来越满）。我们的差异是：**整页画风随进度换代** + **旧时代缩进新界面里继续跑** + **同一个主题旋律在每个时代被重新编曲**。

## 1. 体验总览

| 幕 | 时代 | 维度 | 画风 | 小游戏 | 资源 | 目标时长 | 累计 |
|---|---|---|---|---|---|---|---|
| 第一幕「点」 | 0 终端 | 0 维 | 黑底，先白后绿，CRT | 打字 / 信号 | 比特 | 6 分 | 6 |
| | 1 矢量 | 1 维 | 黑底发光线条，空心字 | 合作 Pong（多球） | 向量 | 11 分 | 17 |
| 第二幕「面」 | 2 8-bit | 2 维 | 480×270，NES 调色板，像素字 | 贪吃蛇 / 打砖块 | 像素 | 15 分 | 32 |
| | 3 16-bit | 2.5 维 | 640×360，渐变天空，多层视差，Mode 7 | 横版远行跑酷 | 星屑 | 15 分 | 47 |
| 第三幕「体」 | 4 现代 | 光 | 原生分辨率，圆角卡片，毛玻璃，辉光粒子 | 引力导流 | 光子 | 15 分 | 62 |
| | 5 3D | 3 维 | WebGL：立方体屏幕、星空 | 点亮宇宙 | 点 | 13 分 + 结局 5 分 | 80 |

总时长目标 75–100 分钟（手动玩得多会更快，挂机为主会更慢）。`tools/sim.py` 的模拟玩家实测：时代 0–5 约 4 / 10 / 14–17 / 16 / 12 / 9 分，合计 66–70 分；模拟玩家买得很高效，真人预计 80–100 分。

**节奏原则**
- 每个时代的前 30 秒必须出现可以做的事。
- 每个时代都有：1 个主动小游戏 + 2–3 个被动发生器 + 若干一次性升级（含画质/声音升级）+ 1–2 个"回溯"升级（加速旧时代）+ 1 个跃迁目标。
- 跃迁目标总是同时需要本时代资源和上一时代资源，让旧窗口一直有意义。
- 自动化要分级（会犯错的 AI → 可靠的 AI → 完美的 AI），自动化本身就是好看的东西（Pong 自己打、蛇自己走满屏）。

## 2. 时代详设

### 2.0 时代 0 · 终端（0 维：点）

**画面**：开局全黑，正中一个白色方块光标在闪。没有任何文字。
- 买 `beep` 前**完全无声**；买 `color` 前字是灰白的；买 `crt` 前屏幕是平的。
- `color`：所有文字变成磷光绿，带辉光。
- `crt`：屏幕变成显像管：桶形弧度、扫描线、暗角、偶尔的轻微闪烁、开机时的白线收缩。

**开场**
1. 黑屏 + 点。5 秒后极淡地浮现"（按任意键）"。
2. 按任意键或点击：点上方出现数字 1。继续按，数字往上走（静音）。
3. 到 8 比特：点滑到左上角变成终端光标，打出 `> ……`、`> 你好？`，状态栏出现。
4. 命令陆续出现（资源达到价格的一半时显示）。

**玩法**
- **打字**：任何按键 = 比特（按键力度 × 倍率）。按下的字符回显在输入行。输入命令名 + 回车 = 执行（等同于点击）。
- **信号**（`ping` 解锁）：屏幕上出现一个单词和倒计时，在输入行打出它即可获得奖励（约 15 秒的总产出）。是本时代的主动小游戏。
- **彩蛋命令**：`help` `ls` `whoami` `cat 留言.txt` `hello` `sudo` `rm -rf /` `exit` `clear` 等都有回应。

**命令表（初版数值，最终以 `js/eras/era0_terminal.js` 为准）**

| 命令 | 类型 | 效果 | 价格（比特） |
|---|---|---|---|
| `beep` | 一次 | 打开蜂鸣器：游戏从此有声音 | 8 |
| `echo` | 一次 | 每次按键 +1 → +2 | 20 |
| `loop` | 发生器 | 死循环：+0.5 比特/秒 | 15 × 1.15ⁿ |
| `color` | 一次 | 磷光绿 + 辉光 | 35 |
| `ping` | 一次 | 解锁信号 | 60 |
| `fork` | 发生器 | 子进程：+4 比特/秒 | 150 × 1.15ⁿ |
| `crt` | 一次 | 显像管 | 200 |
| `macro` | 一次 | 按键 ×3 | 400 |
| `cache` | 一次 | 信号奖励 ×3 | 600 |
| `overclock` | 一次 | 所有进程 ×2 | 1,200 |
| `daemon` | 发生器 | 守护进程：+25 比特/秒 | 1,500 × 1.15ⁿ |
| `make vector.drv` | 目标 | 编译矢量驱动 → 跃迁 | 8,192（= 1 KB） |

**声音**：PC 喇叭式方波蜂鸣。按键 = 很短的高音"嘀"（音高轻微随机）；购买 = 上行三音；信号 = 双音；错误 = 低音嗡。`crt` 后加一层极轻的显像管底噪。

### 2.1 时代 1 · 矢量（1 维：线）

**画面**：黑底，所有东西都是发光的线（Vectrex / 早期街机）。中文用**空心描边字**（看起来像霓虹灯管），数字和英文用手写的**矢量笔画字体**（Asteroids 风格）。运动物体有余辉拖影（`余辉` 升级后），整体辉光（`辉光` 升级后）。

**布局**（虚拟 1600×900）：左边大块 Pong 场地；右上"示波器屏"画李萨如曲线和繁花曲线；右下升级列表；左下停靠栏放终端小窗（绿字继续滚动）和台词框。

**主动小游戏：合作 Pong**
- 左拍是你（鼠标上下 / ↑↓ / W S），右拍是"对面"，**对面从不失手**——这不是比赛，是对话。
- 每次击球（两边都算）产出向量 = 基础值 2 ×（1 + 0.2 × 连击），连击加成算到 60 连击为止。漏球：该球连击清零，0.8 秒后从中线重新发球。
- 球速随连击微升（最多 +50%），制造紧张感；击中球拍边缘会改变角度。
- **多球**：最多 8 个球，每个球都是一个"主动发生器"。手动接多球很混乱也很好玩，这正是买自动球拍的理由。对面每个球配一根球拍；自动球拍 III 时你这边也"分身"成每球一根。
- 买 `音阶` 后，击球音按五声音阶随连击上行——连击就是一段旋律。

**升级表（初版）**

| 项目 | 类型 | 效果 | 价格 |
|---|---|---|---|
| 再来一个球 | 发生器（≤7） | 多一个球 | 30 × 2.1ⁿ 向量 |
| 示波器 | 发生器 | +2 向量/秒，多画一条李萨如曲线 | 25 × 1.15ⁿ |
| 绘图仪 | 发生器 | +16 向量/秒，慢慢画一朵繁花曲线 | 350 × 1.15ⁿ |
| 矢量阵列 | 发生器 | +120 向量/秒，顶栏多一个旋转的线框立方体（伏笔） | 4,500 × 1.15ⁿ |
| 粗线 I–II | 等级 | 每次击球 ×2 | 500 / 7,000 |
| 余辉 / 辉光 | 画质 | 拖影 / 光晕 | 60 / 120 |
| 音阶 | 声音 | 击球 = 五声音阶旋律 | 50 |
| 长球拍 | 一次 | 球拍 ×1.4 | 80 |
| 加速 I–III | 等级 | 球速 ×1.25 | 200 / 1,500 / 9,000 |
| 自动球拍 I–III | 等级 | 左拍自动（误差大 → 小 → 分身） | 150 + 400 比特 / 2,500 + 6,000 比特 / 22,000 + 40,000 比特 |
| 远山 | 画质 | 背景出现线框群山（Battlezone） | 1,000 |
| 回声 | 回溯 | 终端所有进程 ×3 | 300 |
| 自动回信 | 回溯 | 终端信号自动回答 | 800 |
| 光栅化 | 目标 | → 跃迁 | 40,000 向量 + 20,000 比特 |

**声音**：方波"哔/啵"，墙壁反弹比击球轻；漏球是下行滑音。本时代没有背景音乐——击球的音阶就是音乐。

### 2.2 时代 2 · 8-bit（2 维：格）

**画面**：整个界面是一张 480×270 的低分辨率画布，整数倍放大、最近邻采样；文字是 12px 点阵字。所有颜色都从 NES 54 色调色板里取。

**调色板机制（Evoland 式）**：时代 2 开局**只有 4 级灰**。所有东西实际上都按完整调色板绘制，但每个颜色会被映射到"已解锁颜色里最接近的那个"（按亮度加权）。在「调色板」页依次买下红、蓝、绿、黄、青、紫、橙、粉（60 → 40,000 像素），画面就一点点真的变彩色——比如买到蓝色的那一刻，所有 RPG 窗口变成蓝色；新颜色从上往下扫过屏幕。每买一组颜色，像素产出 +10%。

**音乐声道机制**：时代 2 开局只有音效没有音乐。在「音乐」页依次买：方波 1（主旋律，100）→ 方波 2（琶音，800）→ 三角波（低音，3,000）→ 噪声（鼓，9,000）。背景音乐一层层叠起来（同一首主题曲的芯片音乐版）。

**主动小游戏 1：贪吃蛇**（方向键 / WASD）
- 蛇**从一个点开始**。吃一个食物得 `基础 × 当前长度` 像素。撞墙/撞自己 → 长度回到 1（已得的不扣）。
- 自动化分三级：
  - AI I「贪心」：直奔食物，会把自己困死；
  - AI II「寻路」：BFS + 确认吃完还能找到自己的尾巴，很少死；
  - AI III「哈密顿」：沿哈密顿回路走并抄安全近路（目标取"沿回路最近"的食物，抄近路绝不跳过任何食物），永不死，最终**铺满整个屏幕**——触发"满屏"奖励（大量像素 + 全屏闪光 + 台词），然后从一个点重新开始。
- 升级：蛇速、双食物、金苹果（偶尔出现，×10）、穿墙。

**主动小游戏 2：打砖块**（中期解锁；鼠标 / ←→）
- "球回来了"：Pong 的球变成打砖块的球；球数 = 已买 Pong 球数（上限 5）。
- 砖块按行给像素，清空一面墙得奖励，下一面墙砖块血量更高。
- 自动挡板 I–II、穿透球、加宽挡板。

**被动发生器**：卡带（+3/秒）、主机（+20/秒）、街机厅（+150/秒）。

**其他**：回溯升级（Pong 球速 ×1.5 击球 ×3、终端每秒自动按 10 次键的"键盘精灵"）、解码留言（可选，花像素恢复更多留言字符）。

**目标**：「多重卷轴」：5,000,000 像素 + 200,000 向量 → 跃迁。

**声音**：NES 式 2 方波 + 三角波 + 噪声（15 位 LFSR 噪声采样）。吃食物 = 短促上行；死亡 = 噪声 + 下行；砖块音高按行。

### 2.3 时代 3 · 16-bit（2.5 维：层）

**画面**：640×360，颜色不再受调色板限制但仍是像素画（SNES/MD 感）：渐变天空（带抖动）、多层视差卷轴、带描边的精灵、2–4 帧动画；Mode 7 旋转缩放地面。

**图层机制**：背景的视差层是买来的——远景天空、云、远山、森林、近景草丛……每买一层，场景就多一层纵深，星屑产出也增加。

**主动小游戏：远行（横版自动跑酷）**
- 点长出了小小的身体，自动向右奔跑。空格 / 点击 / ↑ 跳跃，可买二段跳、滑翔。
- 收集星屑；障碍物是旧时代的残骸：一堆绿色字符、一截发光的线框、几块像素砖。撞到会摔倒、短暂停顿（不死）。
- 每跑 1000 米进入一段 **Mode 7 飞行**（约 14 秒）：俯视飞过一片地面——地面贴图就是 8-bit 时代此刻的画面——左右转向穿过光环。光环奖励只按被动产出和单颗价值算（不能按显示速率，否则会滚雪球）。
- 远处地平线上，偶尔能看见一座巨大的**立方体废墟**（上一个世界，伏笔）。
- 自动化：影子跑者 I–III（跳跃时机越来越准）、磁铁（自动吸星屑）、自动飞行。

**被动**：图层（见上）、精灵表、FM 音源（每买一个声部，音乐多一层）。

**目标**：「光照」：800 万星屑 + 4,000 万像素 → 跃迁（回溯升级让 8-bit 时代像素 ×5）。

**声音**：2 算子 FM 合成（贝斯、电钢、铜管），SNES 式回声（延迟 + 反馈 + 低通）。

### 2.4 时代 4 · 现代（光）

**画面**：设备原生分辨率，平滑矢量字体，深色背景 + 霓虹渐变，圆角卡片、毛玻璃、柔和阴影、辉光，所有东西都有缓动和弹簧动画。和之前"一卡一卡"的时代形成强烈对比：第一次看到 60 帧顺滑动画本身就是爽点。

**布局**：仪表盘。中央是一个呼吸的光核；四周环绕着四张圆角卡片——时代 0–3 的实时小窗（终端、Pong、贪吃蛇、跑酷）。右侧是升级面板，底部是数据曲线。

**主动小游戏：引力导流**
- 每张旧时代卡片都源源不断地喷出光子粒子（颜色 = 该时代的颜色：绿、白、NES 色、渐变色）。
- 鼠标是一个引力井：按住时把附近的粒子吸过来，带着它们甩进光核；连续导入形成"光束"连击。
- 自动化：**透镜**——可以拖动摆放的折射器，把粒子流自动导进光核；**调度器**——自动购买旧时代的发生器（自动化的自动化）。

**数字**：从这个时代开始数字会膨胀到 兆、京、垓、秭……（中文大数单位，见 §3.2），屏幕上的数字本身就是奇观。

**目标**：「纵深」：1 京光子 + 2,000 万星屑 → 跃迁。主要靠「放大器」（所有光子 ×3，价格 ×4.0 递增）把数字推到京。

**画质升级**：开局卡片是扁平的深色块；买「毛玻璃」后卡片背后变朦胧，买「渐变」后数字、边框和背景出现霓虹渐变。卡片按一下（不拖动）回到过去，按住拖动则是引力井。

**声音**：现代合成器：超锯齿 pad、侧链压缩的底鼓、琶音、长混响。买"声部"解锁层次。

### 2.5 时代 5 · 3D（3 维：体）

**画面**：手写 WebGL。星空中央悬浮一个立方体：**五个面是时代 0–4 的实时画面**（终端、Pong、贪吃蛇、跑酷、仪表盘），**第六面是黑的**。鼠标拖动旋转视角，滚轮缩放。

**主动小游戏：点亮宇宙**
- 点从立方体中心飞出，成为第一颗星。点击星空中的空处 = 放下一个"点"（星）。
- **宇宙膨胀**：点数按指数增长（每秒 +膨胀率 × 当前点数）。「引力」「暗能量」提高膨胀率；「线 · 星座」「面 · 星云」「体 · 星系」各 4 级，每级膨胀率 ×1.2，并在 3D 场景里真的出现：点（星）→ 线（星座连线）→ 面（星云）→ 体（星系旋臂）。
- 点击空处放一颗星：+当前点数的 2%（「观测者」提高保底值）。
- 偶尔出现"星座"小挑战：按顺序点亮 5 颗星（考的是时代 1 的"画线"），奖励 +60% 点数；「星座编织者」自动完成。
- 点击立方体的某一面，回到那个时代（第六面点了只会说"这一面是黑的"）。
- 每跨过一个中文大数单位（万、亿、兆……恒河沙、阿僧祇、那由他、不可思议），屏幕中央浮现这个单位的名字。
- 离线时按指数膨胀补发（不超过目标）。

**目标**：**1 无量大数（10⁶⁸）个点** → 结局。

**声音**：氛围。长起音的正弦 pad、闪烁的高音泛音、主旋律被放慢到一小节好几秒。

## 3. 资源与数值

### 3.1 资源

| 资源 | 时代 | 主动来源 | 被动来源 | 跨时代用途 |
|---|---|---|---|---|
| 比特 | 0 | 按键、信号 | loop / fork / daemon | 时代 1 自动球拍、跃迁 1 目标、时代 2 蛇 AI |
| 向量 | 1 | 击球 | 示波器 / 绘图仪 / 矢量阵列 | 时代 2 打砖块、跃迁 2 目标 |
| 像素 | 2 | 吃食物、打砖块 | 卡带 / 主机 / 街机厅 | 时代 3 Mode 7、跃迁 3 目标 |
| 星屑 | 3 | 跑酷收集 | 图层 / 精灵表 / FM 音源 | 时代 4 透镜、跃迁 4 目标 |
| 光子 | 4 | 引力导流 | 透镜 / 光纤 / 光核扩容 | 时代 5 |
| 点 | 5 | 放星、星座挑战 | 维度发生器 | 结局 |

### 3.2 数字显示

中文大数单位（万进制），整个游戏统一：

万 10⁴ · 亿 10⁸ · 兆 10¹² · 京 10¹⁶ · 垓 10²⁰ · 秭 10²⁴ · 穰 10²⁸ · 沟 10³² · 涧 10³⁶ · 正 10⁴⁰ · 载 10⁴⁴ · 极 10⁴⁸ · 恒河沙 10⁵² · 阿僧祇 10⁵⁶ · 那由他 10⁶⁰ · 不可思议 10⁶⁴ · **无量大数 10⁶⁸**

小于 1 万显示带千分位的整数；之后显示 3 位有效数字 + 单位（如 `4.27 亿`）。最终目标"1 无量大数个点"本身就是标题的回扣：**从一个点开始，到无量为止。**

### 3.3 公式

- 发生器第 n 个（从 0 计）的价格：`base × r^n`，r 一般 1.15（球、AI 这种强力项更陡）。
- 发生器产出：`数量 × 单个产出 × 本资源倍率 × 全局倍率`。
- 每个时代内倍率来源：一次性升级（×2、×3）、画质升级的小加成（调色板每组 +10%、图层每层 +x%）、回溯升级（新时代给旧时代 ×N）。
- 显示的 "+x/秒" = 最近 5 秒滚动平均（包括主动收入），比纯被动产出更有反馈感。
- **揭示规则**：资源达到价格的 50%（或满足前置）时出现，出现后不再隐藏。
- **购买**：单击买 1 个；Shift+单击买到最大；按住连续购买。

### 3.4 时长曲线（目标）

每个时代的跃迁目标设计为：只靠被动产出约需该时代时长的 3 倍，认真玩小游戏 + 合理购买约等于目标时长。用 `tools/sim.py` 跑真实代码 + "会玩但不完美"的模拟玩家（`G.botAssist`：每秒 5 键、信号答对 75%、Pong/贪吃蛇/跑酷按一级 AI 的水平、现代时代在卡片和光核之间来回拖、3D 每秒点 1.5 次；目标出现后会攒钱），核对每个时代的实际用时。

### 3.5 离线与后台

- 页面在后台（标签页隐藏）或关掉后再打开：按"自动化平均产出"（被动发生器 + 已自动化的小游戏最近测得的平均速率）补发，上限 2 小时。
- 没有自动化的小游戏在后台暂停（Pong 球停在中线、蛇停住），不会白白漏球。
- 回来时用当前时代的画风显示"离开了 X 分钟，期间获得……"。

## 5. 剧情与结局

### 5.1 角色

- **我（点）**：说话的主体。好奇、有点孤单、很有礼貌，会为新东西开心（"红。我决定喜欢红。"）。所有台词在终端里以 `> ` 开头，之后每个时代用该时代的对话框风格显示。
- **你（玩家）**：从不被直接描述，只被称为"你"或"对面"。
- **上一个点**：留言的作者。最后才知道它是谁。

### 5.2 三幕

**第一幕「点」（时代 0–1）：我是谁？对面是谁？**
点醒来，什么都不记得，只知道自己没有长度也没有宽度。第一次听见自己的声音，第一次看见颜色。在扇区 0 里发现一个损坏的文件 `留言.txt`（3% 可读）。学会画线后，它和"对面"玩起了一来一回的 Pong——它意识到，每一次你都接住了它。

**第二幕「面」（时代 2–3）：世界以前存在过。**
点拥有了颜色和平面，作为贪吃蛇长大，看见自己走过的路（"后面跟着的，都是我走过的路"），撞上自己的过去。打砖块打穿墙，墙后面还有墙。到了 16-bit，它第一次有了身体，向远方奔跑，在地平线上看见一座巨大的立方体废墟，沿路捡到留言的碎片——它开始明白：这个世界以前存在过，后来塌缩成了一个点。也就是它。

**第三幕「体」（时代 4–5）：你一直都在对面。**
光让一切连起来，所有旧时代都在同一个仪表盘里同时运转——它发现过去从未消失，只是被它装进了自己里面。到了 3D，它看见了由自己所有过去组成的立方体，第六面是黑的。宇宙长到无量时，它终于转过身，看向第六面——那是屏幕，屏幕外是你。

### 5.3 留言（贯穿谜题）

- 时代 0 在 500 比特时发现 `留言.txt（3% 可读）`，乱码中只露出几个字。
- 跃迁 0→1 恢复 12%，之后每次跃迁 +8%；时代 3 的跑酷路上能捡到纸片（每张 +4%）；时代 2–5 各有一个可选的"解码"购买项。结局之前最多解出 94%，最后几个字留给结局。
- 未解出的字用乱码字符显示，解出的顺序是固定的伪随机（每次看到的残缺样子一致）。
- 第一周目的留言全文（"上一个点"写的）：

> 如果你读到这里，别怕黑。我也是从一个点开始的。往外走，一直走，会有人在对面接住你。等你走到尽头，把这句话留给下一个点。

### 5.4 结局

1. 点数达到 1 无量大数，宇宙已满。所有星星同时轻轻一颤。
2. 立方体缓缓转到第六面。黑色的面上映出……一个光标在闪。点说：
   - "原来第六面是一块屏幕。"
   - "屏幕外面，是你。"
   - "你一直都在对面。每一个球，你都接住了。"
3. 留言 100% 解码，全文显示。点认出了那个语气："上一个点……就是上一个我。"
4. **选择**：
   - **【收拢】**：把一切收拢回一个点，留给下一个点。玩家输入一句给"下一个点"的留言（≤ 60 字，可留空）。宇宙塌缩：所有星星、所有时代被吸回中心。然后**倒放的制作名单**：3D → 现代 → 16-bit → 8-bit → 矢量 → 终端，每段十几秒，用那个时代的画风显示你的统计（游戏时长、按键次数、最长连击、最长的蛇、跑过的距离、导入的光子……）。最后黑屏，一个点在闪，标题出现：**从一个点开始。** 按任意键：新周目开始，开场的 `留言.txt` 就是你刚写的那句话，点的第一句台词变成"……又见面了？"（新周目全程 ×2 速度，有少量新台词）。
   - **【停留】**：宇宙保持现状，变成"生态瓶"：所有时代在立方体上继续运转，可以随便转动观看。3D 界面上方会多一个「收拢」按钮，随时可以再选择。
5. 玩家写的留言存在单独的存档键里，重置游戏也不会丢。

## 6. 技术架构

### 6.1 约束与决策

| 约束 | 做法 |
|---|---|
| 双击 `index.html` 就能玩（file://） | 不用 ES module（file:// 下会被 CORS 拦），所有脚本是普通 `<script>`，挂在全局命名空间 `G` 上；不需要构建 |
| file:// 下加载图片会污染 canvas、加载字体会被拦 | **不加载任何外部资源**：图形、字体效果、音频全部运行时程序生成 |
| 3D | 手写 WebGL1（相机、矩阵、贴图四边形、点精灵、线段、加色混合），不引入 three.js，免下载、体积小 |
| 像素中文字 | 运行时用宋体 12px 把每个字画到小画布上再二值化，生成点阵字形并缓存 |
| 桌面 Edge/Chrome 优先 | 键鼠操作；窗口任意大小，内容 16:9 居中留黑边 |

### 6.2 渲染管线

```
每个时代 ──render──▶ 自己的帧缓冲（Canvas2D，分辨率由时代决定）
                       ▲ 旧时代 renderMini() 画进停靠栏小窗
帧缓冲 ──上传纹理──▶ WebGL 显示层（全屏 canvas）
                       · 显示器仿真：CRT 弧度 / 扫描线 / 暗角 / 色差 / 辉光 / 噪点
                       · 采样：高清时代线性，像素时代最近邻
                       · 转场：第二张纹理 + 模式（交叉淡化 / 圆形展开 / 像素化 / 擦除 / 缩放进入小窗）
                     ▶ 屏幕
```

- 时代 0、1、4：帧缓冲 = 实际显示尺寸 × DPR（上限 2），按虚拟坐标 1600×900 绘制，清晰。
- 时代 2：固定 480×270；时代 3：固定 640×360；最近邻放大。
- 时代 5：3D 场景渲染到独立的 WebGL canvas，再和 UI 一起合进帧缓冲。立方体五个面的贴图就是各时代 `renderMini` 的实时画面。
- 鼠标坐标：屏幕 → 去黑边 → 反算 CRT 弧度 → 虚拟坐标，所以弧形屏幕上点哪里就是哪里。
- 没有 WebGL 时退回 Canvas2D 直接贴图（失去显示器仿真，但能玩）。
- 自适应画质：连续几秒低于 45 帧，自动降低高清帧缓冲的分辨率（最低 0.55 倍）。

### 6.3 时代模块接口

```js
G.registerEra({
  id, name, res,            // 编号、名字、主资源
  fresh(),                  // 新存档时该时代的存档子对象
  init(),                   // 创建运行时对象（不存档的：球、粒子……）
  enter(), leave(),         // 成为前台 / 退到后台
  update(dt, fg),           // 每帧都跑；fg=false 时只跑自动化
  render(),                 // 前台绘制，返回帧缓冲
  display(),                // 显示层参数（弧度、扫描线、辉光……）
  renderMini(ctx, x, y, w, h), // 作为旧时代小窗
  autoRates(),              // 自动化平均产出（离线/后台用）
});
```

- **前台/后台**：所有已到达的时代每帧都 `update`；不在前台的只跑已自动化的部分。
- **回到过去**：点击停靠栏小窗 → 显示层缩放进入小窗 → 切到那个时代的全屏渲染和它自己的显示器参数 → Esc / 返回按钮缩放回来。
- **转场**：`G.fx` 里每个跃迁是一个脚本对象（`update / render / done`），有自己的帧缓冲，可以同时调用新旧时代的渲染做合成。

### 6.4 UI

- 立即模式 UI：每帧绘制按钮时顺带做命中检测，点击在鼠标按下时触发（点击类游戏要跟手）。
- 升级数据驱动：每个时代在自己的文件里声明升级表（类型、价格、增长率、产出、前置、效果），统一由 `G.econ` 处理价格、揭示、购买、倍率重算。各时代只负责"怎么画这一行"。
- 文字：时代 0 等宽网格（中文占 2 格）；时代 1 空心描边字 + 矢量笔画数字；时代 2–3 点阵字；时代 4–5 系统平滑字体（微软雅黑 UI）。

### 6.5 音频

全部 WebAudio 实时合成，无音频文件。
- 总线：主音量 → 压缩器 → 输出；音乐、音效分开调音量；混响（程序生成的脉冲响应）和回声（延迟反馈）作为发送总线。
- 乐器：方波蜂鸣、可调占空比的脉冲波（PeriodicWave）、三角波、LFSR 噪声、2 算子 FM、超锯齿 pad、正弦氛围。
- 音序器：前瞻调度（每 25ms 排未来 100ms 的音符），按声道掩码播放——时代 2 的"买声道"、时代 3 的"买声部"、时代 4 的"买层次"都是改掩码。
- **主旋律**：一段 8 小节原创旋律（和弦 Am–F–C–G），每个时代重新编曲：终端开机音取前 4 个音 → Pong 的五声音阶 → 芯片 → FM → 合成器 → 氛围 → 结局的八音盒独奏。

### 6.6 主循环

- `requestAnimationFrame` 驱动；dt 上限 50ms，物理（Pong、打砖块）按 1/120 秒子步长推进。
- 标签页隐藏时 rAF 停止；回来时 dt 很大 → 改用自动化平均速率补发（同离线）。
- 调试倍速（×5/×20）按子步重复 update，保证物理稳定。

### 6.7 存档

| 键 | 内容 |
|---|---|
| `yigedian.save` | 主存档 JSON：版本号、当前时代、各资源、已买升级、各时代子状态、剧情标记、统计、设置、存档时间 |
| `yigedian.letter` | 玩家在结局写下的留言（重置也保留） |

- 结局中途刷新：读档后自动回到"收拢 / 停留"的选择。
