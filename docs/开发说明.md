# 开发说明

> 面向维护者。玩法与剧情设计见 `docs/设计.md`。

## 运行

- 直接双击 `index.html`（file://）即可运行，不需要构建。所有脚本都是普通 `<script>`，通过全局命名空间 `G` 互相访问（file:// 下 ES module 会被 CORS 拦）。
- 游戏不加载任何外部文件：图形、像素字、音频全部运行时生成。file:// 下加载图片会污染 canvas、加载字体会被拦，所以这是硬约束。
- 开发时也可以用本地服务器：`.claude/launch.json` 里配了 `python -m http.server 8765`。

## 部署

- 线上地址：https://dot.xiaoming6680.link（备用：https://from-a-dot.pages.dev）。
- 仓库：https://github.com/xiaoming6680/from-a-dot （公开）。
- Cloudflare Pages 项目 `from-a-dot` 连接了这个 GitHub 仓库：**push 到 main 就自动部署**，不需要构建命令，输出目录是仓库根目录。
- 自定义域名 `dot.xiaoming6680.link` 需要 DNS 里有一条 CNAME：`dot` → `from-a-dot.pages.dev`（开启代理）。
- 所有资源都用相对路径，放在子域名根路径或任意子路径下都能跑。运行只需要 `index.html`、`css/`、`js/`；`docs/`、`tools/` 一起部署上去也无害。
- 本机 wrangler 的 OAuth 令牌只有 Pages 写权限和 Zone 只读权限，改不了 DNS；DNS 要在 Cloudflare 面板里改。

## 架构要点

**渲染管线**：每个时代把画面画到自己的帧缓冲（Canvas2D）。时代 0/1/4 按设备分辨率画（虚拟坐标 1600×900），时代 2 固定 480×270、时代 3 固定 640×360（最近邻放大），时代 5 先用 WebGL 画 3D 再叠 2D HUD。帧缓冲每帧作为纹理交给 `display.js` 的 shader 呈现，shader 负责显示器仿真和跃迁时的双纹理合成。

**时代接口**（`G.registerEra`）：`fresh()` 存档子对象、`init()`、`enter(fromFx, visiting)`、`leave()`、`update(dt, fg)`（所有已到达时代每帧都跑，`fg=false` 时只跑自动化）、`render()` 返回帧缓冲、`display()` 返回显示参数、`renderMini(ctx,x,y,w,h,opt)` 作为旧时代小窗、`music()`、可选 `offline(sec)`。

**跃迁**（`G.fx.xxx`）：工厂函数返回 `{ update(dt), render() → {src, p}, done, interactive? }`。跃迁一开始就 `G.setEra(n)` 并存档，所以中途刷新会直接进入新时代。演出期间台词队列暂停。

**回到过去**：`G.visit(id, rect)` 先把当前画面缩放进小窗区域，再切到旧时代的全屏渲染和它自己的显示参数；Esc 返回。各时代的小窗、卡片、3D 立方体的面都能触发。

**经济**：升级用 `G.econ.define(era, [...])` 声明（`gen` 可重复、`level` 分级、`one` 一次性、`goal` 跃迁目标）。`recompute()` 先跑各时代的默认修正值 hook，再应用已购升级的 `mod`，最后累加发生器产出。`E.gain(res, amt, src)` 统一入账：`src='auto'` 计入自动化平均速率（离线补发用），`'bonus'` 不计入（防止奖励自我放大）。

**存档**：`yigedian.save`（主存档）与 `yigedian.letter`（结局写下的留言，重置也保留）。每 10 秒、页面隐藏、关闭时存档。字段缺失由 `migrate()` 补齐。

## 调试

网址加 `?debug`：右上角调试面板（帧率、倍速、加资源、全买、达成目标、清档）。

- F2 切换倍速（×1/×5/×20/×60），F4 达成当前时代目标，F6 加资源
- 控制台：`G.cheat.toEra(n)` 直接走完跃迁到第 n 个时代；`G.speed = 0` 冻结后用 `G.step(秒, dt, 是否绘制)` 精确推进
- `G.botAssist = true`：各时代的"手动操作"改由模拟玩家完成（数值模拟用）

## 测试工具

需要 Python 版 Playwright 和本机 Edge（`channel="msedge"`）。

| 脚本 | 作用 |
|---|---|
| `tools/sim.py` | 用真实代码 + 模拟玩家从零玩到结局，输出每个时代用时（约 20 秒跑完）。加 `--buys` 打印每样东西首次购买的时间 |
| `tools/smoke.py` | 以 file:// 打开，发真实鼠标/键盘事件，逐个时代检查商店点击（含 CRT 弧度反算）、回到过去与返回、菜单（含点背景关闭不漏点击）、调度器静音、存读档、离线、结局中途刷新恢复、停留模式 |
| `tools/shoot.py steps.json` | 按 JSON 步骤执行 JS 并截图（`VP=960x540` 环境变量改视口） |

截图输出在 `tools/shots/`（已在 `.gitignore`）。

## 已知限制

- 桌面键鼠优先，没有做触屏适配。
- 字体依赖 Windows 自带的宋体（像素字）、微软雅黑、Consolas；其他系统会回退到相近字体，像素字可能不够干净。
- 3D 时代需要 WebGL；不支持时会显示提示，其余时代退回 Canvas2D 呈现（失去显示器仿真）。
