# 《从一个点开始》立项方案

> 立项日期：2026-10-05。这是最初的方案草稿，正式设计以 `docs/设计.md` 为准。

## 一句话
一个有结局的放置/增量游戏，但每到一个阶段，整个网页的"画质时代"升级一次：纯文字终端 → 黑白矢量 → 8-bit → 16-bit → 现代辉光 → 3D。画风突变的那一刻本身就是让人眼前一亮的地方。

## 时代与小游戏（初稿，可调整）
| 时代 | 画风 | 小游戏 / 资源来源 | 声音 |
|---|---|---|---|
| 0 终端 | 黑底绿字，只有文字和一个按钮 | 点击 / 打字产出"比特" | 蜂鸣 |
| 1 矢量 | 黑白线条 | Pong | 方波哔哔 |
| 2 8-bit | NES 调色板 | 贪吃蛇 / 打砖块 | chiptune |
| 3 16-bit | 更多颜色、视差背景 | 平台跳跃或射击 | FM 合成 |
| 4 现代 | 扁平 + 辉光 + 粒子 | 由前面时代的自动化组合而成 | 合成器 |
| 5 3D | WebGL | 终局（结局演出） | 氛围音乐 |

## 关键设计点
- **逐步展开**：像 A Dark Room / Universal Paperclips 一样，开局界面几乎是空的，新按钮、新面板随进度出现
- **每个时代都要能自动化**：手动玩小游戏 → 解锁自动玩 → 产出资源推进下一时代，前一时代缩成后一时代界面里的一个小窗口继续运转（"套娃"感）
- **时代跃迁是演出**：界面重新"渲染"自己，旧元素被新画风替换，要做成全游戏最爽的时刻
- **有结局的弧线**：总长 1–2 小时，三幕结构，结尾回扣"从一个点开始"
- **存档**：localStorage 自动存档，支持离线收益（可选）

## 参考
Evoland、Universal Paperclips、A Dark Room、Stimulation Clicker、Candy Box

## 技术约束
- 纯前端，无后端；桌面浏览器优先（Edge / Chrome）
- 每个时代的渲染风格要能干净地切换（可以是不同的渲染器 / CSS 主题 / Canvas / WebGL），3D 部分可用 three.js
- 最好双击 `index.html` 就能玩；需要构建就用 Vite，产物是纯静态文件
- 界面文案用简体中文
